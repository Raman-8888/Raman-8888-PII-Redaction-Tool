1. EVALUATION STRATEGY OVERVIEW
--------------------------------------------------------------------------------
The evaluation strategy for this PII Anonymization and Redaction Engine assesses 
model performance across legal, corporate, and financial documents 
(e.g., Red Herring Prospectus). A benchmark dataset comprising 4,686 document 
paragraphs and table cells containing 10,725 annotated PII instances was used 
to evaluate entity detection, precision, recall, and overall accuracy.

The system evaluates dual processing modes:
  - Synthetic Replacement Mode (--mode anonymize): Replaces PII with realistic 
    synthetic alternatives (Faker) while preserving document semantics.
  - Static Redaction Mode (--mode redact): Replaces PII with [REDACTED] tokens.


2. METRIC FORMULATIONS
--------------------------------------------------------------------------------
- Precision (P): Ratio of correctly identified PII entities to total detected entities.
    Precision = True Positives / (True Positives + False Positives)

- Recall (R): Ratio of correctly identified PII entities to total ground truth entities.
    Recall = True Positives / (True Positives + False Negatives)

- F1-Score: Harmonic mean of Precision and Recall.
    F1-Score = 2 * (Precision * Recall) / (Precision + Recall)

- Accuracy: Overall ratio of correct classification decisions across document tokens.
    Accuracy = (True Positives + True Negatives) / Total Tokens

4. TRADEOFF ANALYSIS & DISCOVERY
--------------------------------------------------------------------------------
a. Score Threshold Tuning (0.25 vs 0.40):
   Lowering Presidio's default threshold to 0.25 increased Recall from 84.1% to 
   95.2%, ensuring Indian regional names (e.g. Sarthak Malvadkar, Sandesh Bhagwat) 
   were detected.

b. Multi-Pass Auto-Deny Token Propagation:
   Full names detected in high-context sections (e.g. "Contact Person: John Doe") 
   are automatically tokenized ("John", "Doe") into an auto-deny list for Pass 2. 
   This boosted name recall to 96.2% across standalone mentions in table cells.

c. Precision vs False Positives:
   Occasional title-cased corporate terms (e.g. "Certain Directors") were flagged 
   as location/org, resulting in a slight precision tradeoff (91.2% on Location).
