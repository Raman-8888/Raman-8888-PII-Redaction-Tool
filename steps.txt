========================================================================
             ANONYMIZE DOCUMENTS WITH PRESIDIO - SETUP & RUN GUIDE
========================================================================

Prerequisites:
--------------
- Python 3.9+ (Python 3.10+ recommended)
- pip package manager

------------------------------------------------------------------------
STEP 1: Install Required Dependencies
------------------------------------------------------------------------
Open a terminal in the project directory (`PII-Redaction-Tool`) and run:

    pip install presidio-analyzer presidio-anonymizer spacy python-docx python-pptx pymupdf faker flask

------------------------------------------------------------------------
STEP 2: Download the Required spaCy Language Model
------------------------------------------------------------------------
Presidio requires a spaCy English NLP model for entity detection. Download it with:

    python -m spacy download en_core_web_sm

------------------------------------------------------------------------
STEP 3: Launch the Web GUI Application (Recommended)
------------------------------------------------------------------------
To launch the interactive Web Interface:

    python app.py

Open your browser and navigate to:

    http://127.0.0.1:5000

Web GUI Features:
- Drag-and-drop document uploader (.docx, .pdf, .pptx)
- Real-time animated progress bar (0% -> 100%)
- Mode Selector: Synthetic Anonymization (Fake Names, Phones, Emails) vs Static Redaction
- Live Entity Metrics Breakdown Dashboard
- Download button for redacted/anonymized documents

------------------------------------------------------------------------
STEP 4: Run via Command Line Interface (CLI Options)
------------------------------------------------------------------------

Option A: Synthetic Anonymization (Fake Replacements)
----------------------------------------------------
    python scripts/anonymize_document.py "input/your_document.docx" "output/your_document_anonymized.docx" --mode anonymize --report

Option B: Static Redaction ([REDACTED] Tokens)
----------------------------------------------
    python scripts/anonymize_document.py "input/your_document.docx" "output/your_document_redacted.docx" --mode redact --report

Option C: Force Redact Custom Names / Words (Deny List)
-------------------------------------------------------
    python scripts/anonymize_document.py "input/your_document.docx" "output/your_document_redacted.docx" --deny-list "John Doe,Company XYZ"

Option D: Batch Process an Entire Directory
-------------------------------------------
    python scripts/anonymize_document.py input/ output/ --mode anonymize --report

========================================================================
